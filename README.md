# Sales Analysis Dashboard - Power BI

## Project Overview

This project is an interactive Sales Analysis Report developed using Microsoft Power BI.

The report provides an overview of sales performance through key business metrics such as total orders, revenue, profit, returns, and return rate. It also allows users to analyze product performance, monthly trends, regional performance, and order distribution through interactive visuals.

The report consists of four pages:

1. Executive Dashboard
2. Products Dashboard
3. Regional Analysis
4. Decomposition Analysis



## Objectives

The main objectives of this project are:

- Analyze overall sales performance
- Track total orders, revenue, profit, and returns
- Monitor return rate
- Analyze monthly sales and order trends
- Compare product categories and subcategories
- Analyze product-level performance
- Analyze return rate across different regions
- Provide interactive filtering and navigation
- Explore order distribution using decomposition analysis

### 4. Decomposition Analysis

The Decomposition Analysis page is used to break down total orders across different levels of the data.

The analysis follows the hierarchy:

Total Orders  
→ Category  
→ Subcategory  
→ Product

For example:

Total Orders  
→ Accessories  
→ Tires and Tubes  
→ Patch Kit/Patches

This allows users to explore how individual categories, subcategories, and products contribute to the overall number of orders.

## Interactive Features

The report includes several interactive features:

### Filters

Users can apply filters to analyze the data based on available dimensions such as year, subcategory, product, and region.

### Dynamic Visuals

The report contains interactive visuals that respond to user selections and filters.

### Page Navigation

Navigation controls allow users to move between the different pages of the report.

### Report Controls

The report includes filter and reset controls to improve navigation and usability.

### Decomposition Analysis

The decomposition visual allows users to analyze total orders by moving from category to subcategory and then to individual products.



## Key Metrics

| Metric | Description |
|---|---|
| Total Orders | Total number of orders |
| Total Revenue | Total revenue generated |
| Total Profit | Total profit generated |
| Total Returns | Total number of returns |
| Return Rate | Percentage of orders that were returned |
